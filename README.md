# Метродат

Статический одностраничный сайт по макету Figma. Реализация использует HTML, CSS и небольшой JavaScript для мобильного меню и аккордеона; изображения и SVG лежат локально в `assets/`.

## Запуск

Из этой папки запустите:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

## Проверка

- Навигация ведет к разделам страницы.
- Мобильное меню открывается кнопкой в шапке.
- Аккордеон раскрывает один пункт за раз и обновляет `aria-expanded`.
- Почта и телефон в контактных ссылках открывают соответствующие приложения.
